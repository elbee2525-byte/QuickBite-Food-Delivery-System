Project Overview

QuickBite is an online food delivery application that allows customers to browse available meals, add food items to a shopping cart and submit orders online.


The system also provides an administrative dashboard where customer orders can be viewed and managed. It uses a database to store submitted order information.

Problem Statement

Traditional food ordering can involve delays, manual communication and difficulties tracking customer orders. QuickBite provides a digital platform that simplifies the ordering process.

Project Objectives

Easy Ordering

Allow customers to browse meals and submit food orders online.

Shopping Cart

Calculate the total cost of selected food items automatically.

Order Storage

Store customer order information in an SQLite database.

Administration

Provide an admin dashboard for viewing customer orders.

Key System Features

🍔 Food Menu

Customers can browse available meals and prices.

🛒 Shopping Cart

Customers can add meals and calculate their total.

📦 Checkout

Customers submit their names, phone numbers and delivery addresses.

📊 Admin Dashboard

Administrators can view orders submitted by customers.
